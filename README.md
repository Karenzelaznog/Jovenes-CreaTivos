# SKINCARY

Tienda de skincare hecha en Colombia. Proyecto final, Ruta Avanzada de Jóvenes CreaTIvos.

## Estructura
- `frontend/`: interfaz en React (Vite)
- `backend/`: API en Node + Express

## Sitio web
Cada cambio en `main` que afecte `frontend/` se publica automáticamente en
[https://karenzelaznog.github.io/Jovenes-CreaTivos/](https://karenzelaznog.github.io/Jovenes-CreaTivos/).

La tienda, los pedidos, el inicio de sesión de administración y el formulario
de contacto requieren que el backend esté desplegado y que `VITE_API_URL`
apunte a su URL pública.
